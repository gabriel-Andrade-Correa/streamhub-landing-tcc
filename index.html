Qual problema o StreamHub resolve?

Usuarios convivem com varias plataformas, catalogos fragmentados e excesso de opcoes. O resultado e indecisao e perda de tempo antes de assistir qualquer conteudo.

Catalogo fragmentado

Cada app exibe apenas o proprio acervo, dificultando a descoberta global.

Busca ineficiente

Pesquisar titulo por titulo em apps diferentes gera friccao no uso diario.

Decisao lenta

Sem contexto e recomendacao personalizada, o usuario gasta tempo sem decidir.

A proposta de valor

StreamHub unifica descoberta, recomendacao e redirecionamento oficial.

O app agrega dados de catalogo, prioriza o perfil do usuario (genero favorito e plataformas selecionadas), organiza sugestoes relevantes e permite abrir rapidamente o conteudo no app/web oficial.

Passo 1

Usuario escolhe plataformas e preferencias no onboarding/configuracoes.

Passo 2

Backend consolida dados de catalogo via TMDB e complementa links via Watchmode.

Passo 3

App exibe tendencias, novidades e recomendacoes com filtros prontos para decisao.

Passo 4

Usuario abre o conteudo no streaming oficial ou salva na watchlist para depois.

Funcionalidades de destaque

Funcionalidades implementadas no app mobile e no backend para suportar descoberta, personalizacao e usabilidade.

Home inteligente

Chegaram agora, em alta e recomendados para voce em uma unica tela.

Busca global

Busca por titulo e por ator/atriz com dedupe e ordenacao por relevancia.

Detalhes + deep link

Sinopse, disponibilidade e abertura direta no app ou fallback web oficial.

Watchlist pessoal

Lista local para nao perder titulos e sorteio rapido para decidir o que ver.

Modo aleatorio avancado

Sorteio por genero/tipo/plataforma, incluindo modo de embate entre titulos.

Diagnostico de erros

Logs locais de requests para apoiar depuracao, confiabilidade e manutencao.

Arquitetura tecnica

Estrutura modular com backend em Node.js/Express e app mobile em React Native + Expo.

Backend

API REST com integracao TMDB/Watchmode, cache em memoria, regras de recomendacao e persistencia de preferencias/historico em SQLite.

Node.js Express SQLite Axios Jest + Supertest

Mobile

Aplicativo multiplataforma com navegacao por abas, estado global via contexto e persistencia local para watchlist, onboarding e logs de diagnostico.

React Native Expo TypeScript AsyncStorage Deep Linking
